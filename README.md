## Deskripsi Singkat Proyek
Proyek ini diperbarui yang dimana merupakan lembar kerja atau tugas berbasis Outcome-Based Education (OBE) untuk Praktikum Pemrograman Web yang dikembangkan menggunakan lingkungan lokal Laragon.

## Teknologi yang Digunakan
* HTML / PHP
* Apache Web Server (Laragon)
* Git & GitHub

## Cara Menjalankan Proyek Melalui Laragon
1. Pastikan aplikasi **Laragon** sudah terinstal di komputer Anda.
2. Buka aplikasi Laragon, lalu klik tombol **Start All** untuk menyalakan Apache dan MySQL.
3. Letakkan folder proyek ini (`pemweb-obe`) di dalam direktori `laragon\www\` (biasanya di `C:\laragon\www\pemweb-obe`).
4. Buka browser dan akses URL lokal proyek.
